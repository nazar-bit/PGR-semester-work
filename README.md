C++ OpenGL Rendering Engine

A custom 3D rendering engine built in C++ using the OpenGL API. This project demonstrates an understanding of low-level computer graphics principles, linear algebra, and algorithmic implementation, culminating in a pre-built interactive 3D office space scene.

## Features
* **Phong Lighting Model:** Implemented custom vertex and fragment shaders to calculate ambient, diffuse, and specular light for realistic object illumination.
* **Shadow Mapping:** Engineered a multi-pass rendering technique to generate dynamic, visually accurate shadows across the scene.
* **NURBS Curves:** Self-implemented Non-Uniform Rational B-Splines (NURBS) from scratch to handle smooth mathematical curve generation.
* **Applied Mathematics:** Extensive use of linear algebra (matrix transformations, vector operations) for robust processing of spatial data, camera movement, and 3D elements.


## Usage
A compiled executable is located in the `windows` directory. 
*Note: There is a known compatibility issue that may cause rendering artifacts or instability on certain NVIDIA GPUs.*
